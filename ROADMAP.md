# Roadmap

## Done
- Gear optimizer: best owned loadout per style, GE upgrades, budget plan
- RuneLite plugin exporting bank, worn gear, inventory and levels

## In progress
- Quest gear: plugin reads quest progress; for each unfinished quest with a fight, recommend gear
  that follows the fight's rules (required items, style or spell limits)

## Next
- **GitHub Pages version**: plugin serves its data on localhost instead of only writing a file; page calls
  the wiki price API directly (or a scheduled Action publishes prices); Action builds and deploys the site
- **Plugin auto-detects** current slayer task and unlocked prayers (Rigour, Augury, Deadeye, Mystic Vigour)
- **Untradeable upgrades** with where they come from (fire/infernal cape, Barrows gloves, defenders, quest rewards)
- Count ammo cost in the budget; read the blowpipe's loaded dart
- More owned-item sources: POH costume room, group storage, looting bag
- Special attacks, god spells, Iban Blast, Magic Dart

## Companion features (from Mystix)
**Syncing**: farming, bird house and Tears of Guthix timers; skills/XP; bank and value; loadouts; loot log;
collection log; quests and diaries; combat achievements; boss KC; slayer task, points and streak; deaths;
Kingdom of Miscellania

**In game**: goal overlay with progress bar; goal-complete popup and sound

**Notifications**: push alerts when patches and bird houses are ready; manual timer reset from phone

**Views**: bank viewer; drop log with rates; collection log / quest / diary / CA tracker; automatic trip
log; weekly recap; skill guides; slayer hub; world map; hiscores lookup without the plugin

**Planning**: goal tree; boss battle plans; inventory and rune pouch layouts; DPS comparison of saved
setups; farm route planner; collection log and achievement suggestions

**Stats**: drop luck vs wiki rates; personal slayer odds; crashed star tracker; stream overlays
